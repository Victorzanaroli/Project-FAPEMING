# Roteiro de Aula — Aula 08 (Trilha Mobile)

## Sprint do App Mobile + IA + GEMINI.md

**Duração total:** 180 minutos (3h00) — **Horário:** 15h00 às 18h00
**Público-alvo:** Estudantes do Ensino Médio
**Pré-requisitos:** Protótipo do App em Flet/Python funcional, conceitos das Aulas 1–7

---

## Bloco 1: Revisão Rápida dos Protótipos (15 min)

Cada equipe mostra a tela inicial do App Mobile e diz qual problema resolve.

---

## Bloco 2: Aula Expositiva — GEMINI.md para Projetos Mobile (30 min)

**Objetivo:** Ensinar a criar o arquivo `GEMINI.md` na pasta do projeto para orientar a IA a respeitar as regras do código e o formato visual mobile.

```markdown
# Projeto: [Nome do App Mobile]

## Regras do Projeto
1. Usar Python + Flet com tema escuro (Dark Mode).
2. O layout deve ser vertical adaptado para tela de celular.
3. Não usar bibliotecas não autorizadas.
4. Código modular com funções separadas com def.
```

---

## Bloco 3: Sprint de Desenvolvimento do App (25 min)

**Desenvolvimento focado (Parte 1):**
1. Escrever as funções lógicas em Python (`def`).
2. Conectar as funções aos botões (`ElevatedButton`) e campos (`TextField`).

---

## Bloco 4: Sprint de Testes e Ajustes Finos no Celular (55 min)

**Desenvolvimento focado (Parte 2):**
1. Testar a execução no Pydroid 3 do celular e no computador.
2. Resolver erros e bugs visuais com a IA no navegador.
3. Validação do fluxo completo de uso.

---

## Bloco 5: Preparação da Apresentação e Ensaio do Pitch (25 min)

Estruturar a apresentação de 5 minutos:
1. O Problema (30s)
2. A Demonstração do App no Smartphone/PC (2min)
3. O Código e as Funções (1min30s)
4. Como a IA Ajudou (1min)

---

## Bloco 6: Encerramento e Checklist Final da Apresentação (15 min)

Verificação dos arquivos dos apps gravados nos celulares/drive e orientações gerais para a Feira de Soluções.
