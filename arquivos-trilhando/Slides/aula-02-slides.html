O que é uma Variável?

Uma caixa etiquetada na memória do computador onde guardamos valores para usar depois.

Tipos Fundamentais

Textos (strings), números inteiros (int), decimais (float) e valores lógicos (bool).

Interatividade

CONCEITO 1 • VARIÁVEIS

Variáveis e Atribuição

O operador de atribuição = armazena o valor da direita no nome da esquerda

📌 Regras de Nomenclatura

  • Use nomes descritivos em minúsculo com underline (nome_usuario).
  • Não pode começar com números nem usar caracteres especiais/acentos.
  • Sensível a maiúsculas (idade ≠ Idade).

💻 Exemplo em Python

# Criando variáveis (atribuição) nome = "Ana Clara" idade = 16 altura = 1.65 estudante = True print(nome, idade)
CONCEITO 2 • TIPOS DE DADOS

Os 4 Tipos Primitivos do Python

Como o Python categoriza os dados

str (String)

Texto delimitado por aspas simples ou duplas.

"Maria"

int (Integer)

Números inteiros, positivos ou negativos.

42

float (Float)

Números reais com ponto decimal.

7.5

bool (Boolean)

Valores lógicos: True ou False.

True
CONCEITO 3 • ENTRADA DE DADOS

Entrada de Dados com input()

Capturando a digitação do usuário no terminal

⚠️ O Erro Comum de Concatenação

n1 = input("Digite um número: ") # ex: "5" n2 = input("Digite outro: ") # ex: "3" print(n1 + n2) # Resultado: "53" (juntou textos!)

✅ A Solução: Conversão de Tipo (Casting)

n1 = int(input("Digite um número: ")) # 5 n2 = int(input("Digite outro: ")) # 3 print(n1 + n2) # Resultado: 8 (soma numérica!)
CONCEITO 4 • SAÍDA FORMATADA

Interpolação com f-Strings

Formatando mensagens elegantes e dinâmicas com o prefixo f""

💻 Sintaxe das f-strings em Python

nome = "Lucas" pontos = 150 nivel = 3 # Usando f-string para mesclar texto e variáveis mensagem = f"Olá {nome}! Você tem {pontos} pontos no nível {nivel}." print(mensagem) # Saída: Olá Lucas! Você tem 150 pontos no nível 3.
