CONCEITO 1 • OPERADORES

Operadores de Comparação

Toda comparação retorna um valor Booleano (True ou False)

📋 Tabela de Operadores

  • == Igual a (Atenção: não confunda com =!)
  • != Diferente de
  • > Maior que / < Menor que
  • >= Maior ou igual / <= Menor ou igual

💻 Exemplos Práticos

idade = 18 print(idade >= 18) # True print(idade == 20) # False print(idade != 15) # True
CONCEITO 2 • SINTAXE CONDICIONAL

A Estrutura if, elif, else

A importância fundamental da indentação em Python

nota = float(input("Digite a nota: ")) if nota >= 7.0: print("🎉 Aprovado(a)!") elif nota >= 5.0: print("⚠️ Recuperação!") else: print("❌ Reprovado(a).")
CONCEITO 3 • LÓGICA BOOLEANA

Operadores Lógicos: and, or, not

Construindo regras de negócio complexas no seu sistema

and (E)

Verdadeiro apenas se todas as condições forem verdadeiras.

if idade >= 18 and cnh: print("Pode dirigir")

or (OU)

Verdadeiro se pelo menos uma condição for verdadeira.

if estudante or idoso: print("Meia entrada")

not (NÃO)

Inverte o valor lógico (Verdadeiro vira Falso e vice-versa).

if not chovendo: print("Vamos ao parque")
